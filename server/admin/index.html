Rezervasiya sistemi

Rezervasiyalar bu paneldən idarə olunmur — saytdakı forma sorğunu bu serverə göndərir, server isə onu aşağıda göstərilən API vasitəsilə rezervasiya tətbiqinizə (Vilka) ötürür. Masaların təsdiqi və idarəsi tətbiqin öz panelində aparılır. Aşağıdakı jurnal yalnız çatdırılmanı izləmək üçündür.

API bağlantısı

Açar hələ yoxdursa «Sönülü» qoyun — sayt işləməyə davam edir.
Tətbiq tələb edirsə doldurun
Rezervasiyanın POST ediləcəyi ünvan — tətbiqdən alınır
Açar yadda saxlanılır və bir daha göstərilmir.
Bəzi sistemlər X-Api-Key istəyir
Öncə lazım deyilsə boş buraxın
Tətbiq başqa sahə adları gözləyirsə burada uyğunlaşdırın: «bizim ad» → «onların adı»
Hər sorğuya əlavə olunur
Çatdırılmayan rezervasiya bu qədər dəfə yenidən göndərilir

Başqa restoran üçün istifadə

Bu repo şablon kimi istifadə oluna bilər. Yeni restoran üçün:

  1. Reponu klonlayın və npm run new-site işlədin — mətnlər boş şablona qayıdır.
  2. Bu paneldən restoran məlumatlarını, menyunu, şəkilləri və rəngləri doldurun.
  3. .env faylında rezervasiya sisteminin (Vilka və s.) ünvanını və admin şifrəsini təyin edin.

Sayt strukturuna toxunmaq lazım gəlsə, şablonlar src/pages/ və src/partials/ qovluqlarındadır.
