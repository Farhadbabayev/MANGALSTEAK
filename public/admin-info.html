İdarəetmə paneli

Panel bu ünvanda işləmir

Sayt Vercel-də yerləşir — orada fayllar yalnız oxunur, ona görə panel məzmunu birbaşa dəyişə bilmir. Panel öz kompüterinizdə işləyir, dəyişiklik isə saytda avtomatik yenilənir.

  1. Reponu kompüterinizə yükləyin və npm start yazın
  2. http://localhost:3000/admin ünvanını açın və məzmunu dəyişin
  3. git push — Vercel saytı bir neçə saniyəyə özü yeniləyir
git clone https://github.com/Farhadbabayev/MANGALSTEAK.git
cd MANGALSTEAK
cp .env.example .env    # ADMIN_PASSWORD təyin edin
npm start

Rezervasiya sisteminin (Vilka) ünvanı və açarı Vercel-də Settings → Environment Variables bölməsindən təyin olunur.
